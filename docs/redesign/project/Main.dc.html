Night Vision vs Thermal Imaging: Which One Do You Actually Need?

By Shaun, GoingDark

TL;DR. Night vision sees light while thermal sees heat. Everything else hinges on that one difference.

So which one should you buy? Let's start with that difference and work out what it means in the paddock.

What You See Through Each

When you look through a thermal you see a black and white picture where anything warm glows. A pig in the grass is a bright shape. A fox moving along a fence line is a bright shape.
